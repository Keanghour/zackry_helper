# zackry-cli

A command line helper. Run `zackry helper` to see what it can do.

## Install

```bash
pip install zackry_cli-0.1.0-py3-none-any.whl
```

## Usage

```bash
zackry helper     # banner + list of commands
zackry i          # create a FastAPI or Spring Boot project
zackry e          # encryption tools (AES-256-GCM or RSA)
zackry d          # create Dockerfile + .dockerignore (FastAPI or Spring Boot)
zackry version    # show version
```
